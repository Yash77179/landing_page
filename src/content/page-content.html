01 Review

Every PR reviewed before a human touches it.

We built this at a hackathon. It runs Semgrep static analysis + AI on every pull request — automatically. The bot posts before your reviewer even opens the PR.

  • Zero config required

    Install the GitHub App, push a PR — done. No YAML, no setup pipeline, no DevOps wizardry needed.

  • Runs on every push

    Every commit triggers a fresh review. The check starts the moment code lands on GitHub.

  • Semgrep + AI, combined

    Static analysis catches known patterns. The AI layer reasons about context — catching what rules miss.

  • Nothing auto-merges

    We flag issues. You decide. The bot never merges, never blocks — just gives you the intel you need.

02 Findings

Critical issues surface instantly.

SQL injection. Command injection. Exposed secrets. The AI reads your diff and surfaces what actually matters — with CWE references, confidence scores, and suggested fixes inline.

  • Severity-ranked findings

    Critical and High float to the top. Medium and Low follow. You always know what to fix first.

  • CWE-classified + confidence %

    Every finding maps to a CWE. Every AI finding includes a confidence score — 99% means act now.

  • Inline code comments

    Findings land as threaded PR comments on the exact lines. Your team sees them without leaving GitHub.

  • Suggested fixes included

    Not just "this is broken" — we show you the corrected version right next to the vulnerable code.

03 Verdict

Clean code gets a clean pass.

When your PR passes both Semgrep and AI review, you get a clear "All Clear" — not a wall of false positives. Signal over noise, always.

  • Two-layer validation

    Semgrep static analysis first. AI reasoning second. Both must pass before the green check appears.

  • Honest zero-findings result

    We don't pad reports. If nothing's wrong, we say so plainly — "No security or quality issues found."

  • PR check status

    The GitHub Checks API shows "Clean — No issues found" right on the PR. Reviewers see confidence, not ambiguity.

  • Review in 3 minutes

    Built for speed. A typical PR gets its full Semgrep + AI verdict in ~3 minutes — before the first human reviewer even clicks in.

04 Security

Annotated. Classified. Actionable.

When issues are found, you don't get a vague warning. You get the file, the line, the CWE, the severity, and the exact reason it's a problem — all in the GitHub Checks UI.

  • File-level annotations

    Each finding pinpoints the exact file and line. No hunting through logs — GitHub shows it right on the diff.

  • Supply chain risk detection

    Catches third-party Actions pinned to mutable branch refs — the kind of supply chain risk most tools miss entirely.

  • Permissions analysis

    Flags workflows missing explicit permission blocks before they inherit overly broad default token access.

  • Built at a hackathon. Works in prod.

    We shipped this in 12 hours. It's already catching real vulnerabilities in real pull requests.
